\section{Notation}
$\rs r$ regex size; $\card X$ cardinality (a row \emph{count}); $\rss X=\sum_{x\in X}\rs x$ (opened
\emph{size}). $\Strong$ = strong simplifier (collapses $a^{*}\seq a^{*}\!\to a^{*}$); $\sigf$ = weak
sequence plug (\emph{no} collapse); $\dlf(x)$ opens one regex to its linear forms; $\dpar k$ the frontier.
The Antimirov structures:
\[
\Terms(r):\quad \Terms(c)=\{\one\},\quad

\Terms(r^{*})=\bigl(\lambda p.\sigf(p,r^{*})\bigr)\,\Terms(r),

\[
\Rows(r)=\{r\}\cup\dpar r\cup\!\!\bigcup_{t\in\Terms(r)}\!\!\dpar t,\qquad
\boxed{\ \Univ(r)=\bigcup_{q\in\Rows(r)}\dlf(\Strong q)\ }\quad(\text{the strong-opened gate universe}).

\section{The goal and the GREEN chain (reductions all machine-checked, $0$ sorry)}
The clean-fragment thesis target, uniformly in the input $s$:
\[
\Gate:\qquad \rss{\Theta(\Delta_c(\mathsf F(r,s)))}\ \le\ 2\,(\rs r+3)^3 .
\]
It has been reduced, green, to a single \emph{count}:
\begin{align}
&\GREEN\quad \Theta(\Delta_c(\mathsf F(r,s)))\subseteq \Univ(r)
   &&\text{(gate rows lie in the universe)}\\
&\GREEN\quad \rss{\Univ(r)}\ \le\ \card{\Univ(r)}\cdot \mathrm{Suc}((\rs r+2)^2)
   &&\text{(each row has size $\le(\rs r{+}2)^2$; \emph{count}$\times$\emph{per-row})}\\
&\GREEN\quad \card{\Univ(r)}\ \le\ \sum_{q\in\Rows(r)}\card{\dlf(\Strong q)}\ (=:\ \mathrm{SUM})
   &&\text{(}\card{\textstyle\bigcup}\le\textstyle\sum\card{},\ \text{card\_UN\_le)}\\
&\GREEN\quad \card{\Rows(r)}\ \le\ \rs r+2
   &&\text{(ROWS; the proven @37190)}\\
&\GREEN\quad \mathrm{SUM}\le 2\rs r+2\ \Longrightarrow\ \Gate
   &&\text{(\texttt{cubic\_gate\_modulo\_sum})}
\end{align}
So the \textbf{entire Gate is green modulo one of the two equivalent count lemmas}:
\[
\boxed{\ \mathrm{SUM}:\ \sum_{q\in\Rows(r)}\card{\dlf(\Strong q)}\ \le\ 2\rs r+2\ }
\qquad\Longleftrightarrow\qquad
\boxed{\ \mathrm{EXCESS}:\ \sum_{q\in\Rows(r)}\bigl(\card{\dlf(\Strong q)}-1\bigr)\ \le\ \rs r\ }
\]
(equivalence: $\mathrm{SUM}=\mathrm{EXCESS}+\card{\Rows(r)}\le \mathrm{EXCESS}+(\rs r+2)$; the
$\mathrm{SUM}\!\leftrightarrow\!\mathrm{EXCESS}$ bridge is \GREEN, due to lane card-2). Both are pure
\emph{counts} (no membership), so the $a^{*}\seq a^{*}$ collapse wall that killed the per-child
distribution route \emph{cannot} apply. Numerically: $\mathrm{SUM}\le 2\rs r+2$ holds $0/186528$ and
$\mathrm{EXCESS}\le\rs r$ holds $0/309763$ (incl.\ the $a^{*}\seq a^{*}$/RALTS killers).
